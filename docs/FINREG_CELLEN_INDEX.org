* Decision

Finreg remains an independent product, deployment, backend, database, and the
sole fiscal system intended for AGT certification. Cellen keeps the school
domain and never embeds Finreg packages:

- the backend calls the Finreg integration API through =finreg-kit=;
- the admin opens standalone Finreg through a single-use delegated launch
  ("Abrir no FinReg"), landing on the workspace home;
- guardians stay in native Cellen screens fed by the =/finreg/parent/*= proxy;
- cash sessions are Cellen-native (=CashSessionsScreen=); the Finreg school
  profile disables them by design.

Schools are fiscal issuers: billing, receivables, payments and recurring
billing stay operational, and the invoice → AGT =valid= → payment → receipt
path remains the acceptance nucleus.

* Governing rule

If these documents conflict, the architecture specification owns system
boundaries, the test/rollout specification owns production safety, and an
approved Architecture Decision Record must resolve the conflict before code
is merged.

* Immediate gate

The cutover window is =deploy_finreg_school_finance.sh --cellen-only=: staged
kit, scope grant, Cellen migration and a =cellen-api= restart only. Finreg is
verified healthy before and after and is never restarted.
