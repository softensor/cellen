* Decision

Finreg remains an independent product, deployment, backend, database, and the
sole fiscal system intended for AGT certification. Cellen retains its school
domain and embeds an adapted Finreg sales/billing user interface. Cellen calls
Finreg through a secure integration boundary; it does not copy Finreg backend
logic or maintain a second fiscal ledger.
