* Safe deployment order

1. Back up the Cellen PostgreSQL database and the existing environment file.
2. Confirm the Git worktree is clean, fetch the integration branch, install
   requirements, and migrate through =0025=.
3. Keep =FINREG_INTEGRATION_ENABLED=false= until the Finreg API and TLS health
   checks pass.
4. Install Finreg separately on port 8003 and provision a company-scoped,
   initially non-fiscal integration client.
5. Store its secret through =FINREG_CLIENT_SECRET_FILE=, enable the connector,
   restart =cellen-api=, and begin in =fake= then =shadow= mode.
6. Do not enable =pilot= or =live= without reconciliation and the documented
   accounting/AGT approvals.
